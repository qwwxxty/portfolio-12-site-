# Mossline

Лендинг вымышленной компании Mossline. Весь сайт находится в `index.html`, включая CSS, JavaScript и пять начертаний шрифтов. Библиотеки и сборка не нужны.

Для просмотра откройте `index.html` в современном браузере. Также можно запустить локальный сервер из папки репозитория.

```sh
python3 -m http.server 4173
```

Затем откройте http://localhost:4173.

Тексты, цвета, изображения и данные карточек меняются в блоке `CONFIG` в начале HTML-файла. Переносы строк задаются через `\n`. Поле `image` у карточки принимает имя ресурса из CONFIG или URL изображения.

Кнопка LET’S TALK открывает контактную заглушку. Чтобы подключить контакт, заполните `CONTACT_URL` ссылкой или адресом вида `mailto:name@example.com`.

Изображения и видео загружаются по адресам из CONFIG, поэтому нужен интернет. При недоступном видео страница использует неподвижный фон. Настройка уменьшения движения в системе отключает полёт камеры, параллакс и декоративные анимации.

Видео сначала кэшируется в JPEG-кадры. Прокрутка выбирает кадры из кэша. В браузерах без `requestVideoFrameCallback`, а также при блокировке автозапуска, кадры собираются последовательным перемещением по видео.
